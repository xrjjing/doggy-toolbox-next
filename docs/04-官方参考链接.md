## 阅读建议

1. **先看 Wails 安装 + CLI**
2. **再看 Vue Quick Start 与 TypeScript 概览**
3. **然后看 Wails Frontend / Project Config**
4. **最后查 Go 语法与工程细节**

原则：

- 桌面壳问题先查 Wails
- 组件 / 路由 / 状态问题先查 Vue
- 类型问题先查 TypeScript
- 并发 / 文件 / 模块问题先查 Go
