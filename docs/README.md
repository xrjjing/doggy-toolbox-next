# docs 导航

## 建议阅读顺序

1. `00-START-HERE.md`  
   先看当前目标、环境准备、为什么这样选型。

2. `05-第一阶段详细执行步骤.md`  
   当你准备“自己开始写”时，先按这个清单逐步走到可自主开发状态。

3. `01-分阶段重写路线.md`  
   看整个重写过程应该按什么顺序推进。

4. `02-目录结构与配置说明.md`  
   看 Wails / Vue / Go 的目录怎么摆，配置文件放哪里。

5. `03-启动与验证流程.md`  
   看第一次启动、开发调试、构建验证到底按什么顺序执行。

6. `04-官方参考链接.md`  
   看后续遇到问题优先查哪些官方资料。

## 文档目标

这些文档的目标不是讲抽象概念，而是回答下面这些问题：

- 从哪一步开始？
- 先装什么？
- 目录怎么摆？
- 配置文件放哪？
- 第一个功能先迁什么？
- 开发时先启动什么，再启动什么？
- 每一阶段完成的判断标准是什么？
- 到什么程度算“我已经可以自己开写”？
